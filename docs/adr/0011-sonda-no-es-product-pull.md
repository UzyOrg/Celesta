# ADR 0011 · La sonda es compromiso declarado, no product pull

- **Fecha:** 2026-08-10
- **Estado:** aceptada
- **Ámbito:** cierre D1, cierre D7 y telemetría de mercado

## Decisión

Después de D1 y D7, “Quiero otro reto” abre una elección concreta de objetivo y un registro
con recordatorio opcional. Los eventos usan `completo_paso` y guardan su semántica dentro de
`result`; no se crea un verbo nuevo.

Un clic, una elección o un registro se llaman interés declarado mediante conducta. Product
pull solo puede empezar a discutirse cuando el alumno se presenta, termina un segundo reto y
vuelve. El pago parental se mide en paralelo y se desglosa como reemplazo, complemento o
gasto nuevo.

## Segundo nodo

Puede prepararse tras 4/5 completions D1 limpias, pero queda oculto hasta D7 y usa otro
constructo. Esto evita ensayar el mismo conocimiento cuya durabilidad intenta medir D7.
