## El fallo después de los switches

Sin la respuesta HTTP ni la configuración de la computadora original no se atribuye aquel
fallo a una causa única. Se comprobaron y cubrieron estos casos:

1. Sin `DEFENSA_SIGNING_SECRET`, la sesión devuelve **503 / no_configurado**, incluso con
   memoria y proveedores mock. Antes guardaba alumno y consentimientos antes de fallar al
   firmar; ahora valida la firma antes de persistir esos datos.
2. La UI admitía cualquier nombre/matrícula no vacíos; el servidor rechazaba, por ejemplo,
   nombre `12345` o matrícula `1` con **400 / solicitud_invalida** después de los permisos.
   Ahora ambas capas comparten las reglas y el navegador explica el error en el campo.
3. `.env.example` deja Supabase como almacén y secretos vacíos; además, el layout compartido
   inicializa Supabase incluso al usar memoria. `npm run dev:defensa` ofrece una demo local
   coherente, con valores ficticios y secretos temporales, sin editar `.env.local`.

Recorrido manual comprobado: datos ficticios válidos → tres switches activados → Aceptar →
«¿Hablas o escribes?». El reintento conserva los switches.

## Qué te corresponde configurar

1. Supabase de pruebas: esquema base de eventos compatible, migración
   `20261013_defensa_oral_piloto.sql` y `20260810_secure_learning_event_readers.sql`.
   Verifica las doce tablas y los buckets privados. Aquí no se ejecutó SQL remoto.
2. Guardar en `.env.local` las variables reales de `.env.example`: Supabase, URL del sitio,
   secreto de firma de 32+ caracteres y secreto de cron de 16+. No pegues llaves en el chat.
3. Elegir modelo y nombres de modelo, un transcriptor (Deepgram o AssemblyAI) y ElevenLabs
   con llave e ID de voz. Solo OpenAI + ElevenLabs no habilita STT en los adaptadores actuales.
4. Ejecutar el diagnóstico sin opciones; después con `--supabase` y `--proveedores`.
   Esta última opción hace llamadas con costo y debe usar únicamente datos ficticios.
5. Validar el archivo con
   `npm run defensa:actividad -- crear docs/defensas/actividad-ejemplo.json --simular`.
   Quitar `--simular` crea la actividad en la base configurada y emite los enlaces.
6. Cargar variables en Vercel Preview y desplegar la rama. Preview ejecuta en producción y
   requiere Supabase; memoria no sirve ahí. `DEFENSA_PUBLICA=1` abre las rutas en ese entorno.
   La configuración del despliegue de producción no se cambió.
